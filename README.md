# Centre for Whole of Society Resilience — website

A static redesign of [wholesocietyresilience.org](https://www.wholesocietyresilience.org). It's plain HTML, CSS and a small JS file, with no framework and no build step needed to host it. Copy is carried over from the original site.

## Pages

| File | Content |
| --- | --- |
| `index.html` | Home: purpose, approach, members, Resilient Leaders Programme, latest news, membership |
| `about.html` | Introduction, founders, steering committee, members |
| `news.html`, `news/*.html` | News index and the four posts |
| `join.html` | Membership charter and sign-up |
| `governance.html` | Steering Group Terms of Reference and site guidelines |
| `404.html` | Not-found page |

## Editing

Shared pieces (header, footer, membership band) appear on every page, so edit the source and regenerate:

```sh
python3 tools/build.py      # rewrites all *.html in the repo root
```

All page copy, team bios and news posts live in `tools/build.py`. Styles are in `assets/css/styles.css` (colour and type tokens at the top). The hero network diagram is generated by `tools/net.py` (run `python3 tools/net.py > tools/net.svg`, then rebuild).

## Replacing the logo

The mark appears in two files only:

- `assets/img/logo-mark.png`: dark version, for light backgrounds (header, page watermarks)
- `assets/img/logo-mark-light.png`: light version, for the dark footer

Both are square, transparent PNGs. Drop in the new logo at the same filenames and it updates everywhere. Also regenerate `assets/img/favicon.png` (64×64) and `assets/img/apple-touch-icon.png` (180×180).

## Hosting

Any static host works (GitHub Pages, Netlify, Cloudflare Pages). Serve the repo root. `.nojekyll` is included for GitHub Pages.

## Features from the Wix site that need a replacement

- **Members Area / member log-in**: Wix-only. The site links to the existing Microsoft Forms sign-up and the LinkedIn group instead.
- **Newsletter subscribe form**: Wix-only. Removed. Add an embed from Mailchimp, Buttondown or similar if needed.
- **Resilient Leaders Programme PDF**: hosted on Wix. Add it to `assets/` and link it from the post if it should stay downloadable.
